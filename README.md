
# QR Scanner

A Django web app to generate QR codes for restaurant menus.

## Features
- Generate a QR code from a menu image
- Success page to view and download the QR code

## Tech Stack
- Python
- Django
- HTML

## How to Run
```bash
git clone https://github.com/KOWSALYAVELU/QR_Scanner.git
cd QR_Scanner
pip install django qrcode pillow
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
